03 SERVIDOR MULTIJUGADOR
⚡ ACTIVAR MULTIJUGADOR LOCAL
El juego funciona 100% solo en el navegador (sin servidor). Para activar el multijugador real con otros jugadores en la misma red:
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor
node server.js

# 3. Abrir desde http://localhost:3000
Requiere Node.js 20+. El servidor escucha en puerto 3000. Para multijugador en red local, otros jugadores acceden por la IP de tu máquina.
